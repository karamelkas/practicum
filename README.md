## Как скачать нужную лабораторную

    git clone -b lab1 https://github.com/karamelkas/practicum.git

## Как переключиться на другую лабораторную

    git checkout lab1

- Ветки `lab1`, `lab2`, `lab3`, ... — код соответствующей лабораторной.
