# Лабораторная работа №1

**Тема:** Командная строка и особенности использования набора компиляторов и утилит GCC

## Вариант 1

1. **task1.cpp** — вычисление произведения n сомножителей вида 2/1 · 2/3 · 4/3 · 4/5 · ...
2. **task2.cpp** — формирование массива из уникальных элементов массива M(25)
3. **task3.cpp** — проверка массива A(20) на строгое возрастание

## Компиляция

    g++ task1.cpp -o task1.exe
    g++ task2.cpp -o task2.exe
    g++ task3.cpp -o task3.exe

## Запуск

    task1.exe
    task2.exe
    task3.exe
